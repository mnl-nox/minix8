01 / O SISTEMA

Um computador inteiro.
Uma ideia de cada vez.

MiniX8 é um computador virtual didático: o núcleo executa código de 8 bits, o monitor permite explorar a máquina e as ROMs carregam seus programas. O mesmo binário funciona em Linux, macOS e Windows.

A

Aprenda por dentro

Inspecione registradores, flags, pilha e memória a cada instrução.

B

Programa em bytes

Use a ISA documentada para construir ROMs e experimentar o ciclo da CPU.

C

Leve e portátil

Implementado em C11. Compile com Make ou CMake, use no terminal ou em container.

03 / DISPOSITIVOS & PROGRAMAÇÃO

Conheça o que está conectado.

A GUI inclui um inventário somente leitura do hardware que Linux, macOS ou Windows publicam. Ele ajuda a inspecionar o computador hospedeiro; não adiciona esses dispositivos à máquina virtual.

Hoje o programa virtual usa console byte a byte por IN/OUT. A ISA inclui `GETCYC` e `GETCYH` para leitura determinística do contador de instruções, mas ainda não tem timer de tempo real, interrupções, NIC, armazenamento guest, USB passthrough, framebuffer ou áudio. O scanner pode listar classes como rede, disco, entrada, áudio, vídeo, serial, Bluetooth e USB/PCI quando o host oferece esses dados.

Escreva assembly MiniX8, monte uma ROM e abra-a na bancada gráfica. A entrada UTF-8 chega à CPU como bytes; o código deve ler cada byte com IN.

06 / ORIGEM, AUTORIA & PROPÓSITO

Entenda a máquina.
Não apenas use-a.

MiniX8 é um projeto independente de computação educacional: uma CPU virtual de 8 bits construída para tornar visíveis conceitos que costumam ficar escondidos atrás de sistemas operacionais, compiladores e hardware moderno.

A ideia central é reduzir a escala sem reduzir a precisão didática. O núcleo em C11 executa uma ISA documentada, com 64 KiB de memória, registradores, flags, pilha, console e monitor de depuração. O projeto também reúne assembler em Python, interface desktop, exemplos, testes automatizados e distribuição multiplataforma.

O repositório público registra a evolução técnica por commits, issues, pull requests, documentação e releases. O histórico público é a fonte apropriada para acompanhar como o projeto evolui.

07 / CURIOSIDADES

Pequena por fora.
Completa o bastante para estudar.

01 / ESCALA

64 KiB inteiros

Com endereços de 16 bits, a máquina pode endereçar 65.536 posições de byte. É um espaço pequeno o bastante para inspecionar diretamente.

02 / EXECUÇÃO

Tempo determinístico

As instruções GETCYC e GETCYH leem os 16 bits inferiores do contador de instruções. A contagem é determinística, não representa segundos nem um timer independente.

03 / CÓDIGO

Bytes viram comportamento

Uma ROM de exemplo usa dez bytes para imprimir “Oi!” e parar. O formato e os opcodes podem ser estudados em vez de tratados como caixa-preta.

10 / FAQ — DÚVIDAS FREQUENTES

Respostas diretas.

MiniX8 é um sistema operacional completo?

Não. É uma máquina virtual didática de 8 bits. A ISO bootável contém um ambiente Linux mínimo hospedeiro que executa o emulador.

É compatível com MINIX 3?

Não. MINIX 3 é uma referência de estudo para conceitos de sistemas operacionais e drivers; MiniX8 tem arquitetura e ISA próprias.

Preciso conhecer C para começar?

Não para executar exemplos. Para estudar o núcleo ou contribuir com a CPU, conhecimento progressivo de C é recomendado. Python é usado nas ferramentas auxiliares.

Como começo a programar?

Leia o guia do usuário e o manual de assembly, monte examples/hello.asm e execute a ROM com o binário MiniX8. A GUI também pode carregar fontes .asm e ROMs.

O MiniX8 controla os dispositivos físicos do computador?

Não. O inventário de hardware do hospedeiro é somente leitura. A CPU virtual não recebe passthrough de USB, rede, áudio ou armazenamento físico.

O que significa o contador de instruções?

É uma contagem determinística de instruções executadas, não um cronômetro de tempo real. GETCYC e GETCYH expõem os 16 bits inferiores.

Qual é a licença?

O código original está sob GPL-3.0-or-later. Componentes externos mantêm suas licenças; consulte LICENSE e THIRD_PARTY_NOTICES.md.

Como reporto um problema ou proponho recurso?

Abra uma issue no GitHub, informe versão, sistema operacional, passos para reproduzir e saída relevante. Para mudanças de código, consulte CONTRIBUTING.md.
